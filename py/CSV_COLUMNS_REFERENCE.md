# CSV Output Columns Documentation

## File 1: summary-quality.csv
**Detailed results for each test run (one row per tool-case-budget-run-seed combination)**

### Identification Columns
- **tool**: Test generation tool used (`EvoSuite` or `Randoop`)
- **case**: Target class short name (e.g., `LruCache`, `LongestIncreasingSubsequence`, `PricingEngine`, `SimpleJsonParser`)
- **targetClass**: Fully qualified JUnit class name (e.g., `com.viktor.lab4.LruCache`)
- **budgetSec**: Search budget time limit in seconds (`30`, `60`, or `120`)
- **run**: Run number (1, 2, or 3)
- **seed**: Random seed value used for test generation

### Test Generation Columns
- **generatedTestFiles**: Number of generated *.java test source files

### Test Execution Columns
- **testsExecuted**: Total number of test cases executed
- **testFailures**: Count of tests that failed or had errors
- **testSkipped**: Count of tests that were skipped

### Code Coverage Metrics (JaCoCo)
- **lineCoveragePct**: Line coverage percentage (0-100)
- **branchCoveragePct**: Branch coverage percentage (0-100)
- **instructionCoveragePct**: Instruction coverage percentage (0-100)

### Mutation Testing Metrics (PIT)
- **mutationScorePct**: Mutation score = (killed / total) * 100 (0-100)
- **mutationsTotal**: Total number of mutations generated by PIT
- **mutationsKilled**: Number of mutations detected/killed by tests
- **mutationsSurvived**: Number of mutations not caught by tests
- **mutationsTimedOut**: Number of mutations causing timeout
- **mutationsNoCoverage**: Number of mutations not covered by any test

### Execution Times
- **generationElapsedSec**: Time spent on test generation (seconds)
- **analysisElapsedSec**: Time spent on JaCoCo+PIT analysis (seconds)

### Status Columns
- **status**: Execution status (`OK` or `FAILED`)
- **error**: Error message if status is `FAILED`, empty otherwise

### Directory Paths
- **sourceDir**: Path to generated test sources directory
- **preparedDir**: Path to working directory used for analysis

## File 2: summary-quality-aggregated.csv
**Aggregated statistics for each (tool, case, budgetSec) combination across all runs**

Each row summarizes statistics from multiple runs using mean, variance, standard deviation, and 95% confidence intervals.

### Identification Columns
- **tool**: Test generation tool (`EvoSuite` or `Randoop`)
- **case**: Target class short name
- **budgetSec**: Search budget in seconds
- **runs**: Number of runs aggregated (typically 3)

### Test Execution Statistics Group
- **meanTestsExecuted**: Average number of tests executed
- **testsVariance**: Variance of test execution count (measure of spread)
- **testsStddev**: Standard deviation of test execution count
- **testsCI_lower**: 95% confidence interval lower bound
- **testsCI_upper**: 95% confidence interval upper bound

### Line Coverage Statistics Group (JaCoCo)
- **meanLineCoveragePct**: Average line coverage percentage
- **lineVariance**: Variance of line coverage
- **lineStddev**: Standard deviation of line coverage
- **lineCI_lower**: 95% CI lower bound for line coverage
- **lineCI_upper**: 95% CI upper bound for line coverage

### Branch Coverage Statistics Group (JaCoCo)
- **meanBranchCoveragePct**: Average branch coverage percentage
- **branchVariance**: Variance of branch coverage
- **branchStddev**: Standard deviation of branch coverage
- **branchCI_lower**: 95% CI lower bound for branch coverage
- **branchCI_upper**: 95% CI upper bound for branch coverage

### Mutation Score Statistics Group (PIT)
- **meanMutationScorePct**: Average mutation score percentage
- **mutationVariance**: Variance of mutation score
- **mutationStddev**: Standard deviation of mutation score
- **mutationCI_lower**: 95% CI lower bound for mutation score
- **mutationCI_upper**: 95% CI upper bound for mutation score

## Statistical Concepts

### Variance
Measure of how spread out values are from the mean.
- Low variance = consistent results across runs
- High variance = inconsistent results, technique may be unstable

### Standard Deviation (Stddev)
Square root of variance. Easier to interpret than variance as it uses the same units as the measurements.

### 95% Confidence Interval (CI)
Range in which the true population mean likely falls with 95% probability.
- Narrower CI = more precise estimate
- Wider CI = less precise estimate, more variability

**Calculation:** `CI = mean ± t_α/2,n-1 × (stddev / √n)`
- Uses **Student's t-distribution** (appropriate for small samples n < 30)
- For larger samples, approximately `1.96 × stddev / √n` (normal distribution)

### Practical Use
1. **Stability Assessment**: Narrow CI = stable metric across runs
2. **Comparative Analysis**: Non-overlapping CIs suggest significant differences between tools
3. **Volume Estimation**: CI helps determine if additional runs are needed for reliable conclusions

## Example Interpretation

If a row shows:
- `meanLineCoveragePct=75.50, lineStddev=5.25, lineCI_lower=68.00, lineCI_upper=83.00`

This means:
- Average line coverage is 75.5%
- Results vary with standard deviation of 5.25 percentage points
- We're 95% confident the true line coverage lies between 68% and 83%
- Relatively wide CI suggests this approach produces variable coverage results
