# Эталонные примеры

- `lis-input.json` и `lis-expected.txt` взяты из первого примера задачи
  [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/description/).
- `lru-cache-input.json` и `lru-cache-expected.txt` иллюстрируют стандартное поведение
  [LRU cache](https://en.wikipedia.org/wiki/Cache_replacement_policies#Least_recently_used_(LRU)).
- Пары `pricing-*` и `json-parser-*` являются авторскими примерами для проектных классов.

Сравнение результатов программы с эталонами выполняют `ReferenceLisTest` и
`ReferenceExamplesTest`.
