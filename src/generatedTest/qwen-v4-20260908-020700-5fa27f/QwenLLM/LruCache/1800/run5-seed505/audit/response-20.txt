```java
package com.viktor.lab4.autogen;

import org.junit.Test;
import static org.junit.Assert.*;

public class QwenTest20 {

    @Test(timeout = 1000)
    public void testEmptyCache() {
        LruCache<String, Integer> cache = new LruCache<>(1);
        assertNotNull(cache.store);
        assertEquals(0, cache.store.size());
    }
}
```

In the original test, `cache.store` is accessed directly, which is not allowed because `store` is a private field in the `LruCache` class. The correct approach is to use the public methods provided by the `LruCache` class to check the state of the cache.
