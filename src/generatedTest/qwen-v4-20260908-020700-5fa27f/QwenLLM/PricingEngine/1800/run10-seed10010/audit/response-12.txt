To fix the failure in the `QwenTest11` test, we need to instantiate the `PricingEngine` class and call the `calculateFinalPrice` method on an instance of it. Here's the corrected code:

```java
package com.viktor.lab4.autogen;

import org.junit.Test;
import static org.junit.Assert.*;
import com.viktor.lab4.PricingEngine;

public class QwenTest12 {

    @Test(timeout = 1000)
    public void testCalculateFinalPriceVipWithLoyalty() {
        // Create an instance of PricingEngine
        PricingEngine pricingEngine = new PricingEngine();

        PricingRequest request = new PricingRequest(
                100.0, // basePrice
                20, // quantity
                PricingEngine.CustomerType.VIP, // customerType
                true, // seasonalSale
                "SAVE10", // couponCode
                true, // firstOrder
                1000 // loyaltyPoints
        );

        double expected = 100.0 * (1.0 - (0.10 + 0.12 + 0.15 + 0.05 + 0.10 + 0.03)) + 7.99;
        double actual = pricingEngine.calculateFinalPrice(request);

        assertEquals("Expected discount is incorrect", expected, actual, 0.001);
    }
}
```

### Key Changes:
1. **Instantiation of `PricingEngine`:**
   - We added `PricingEngine pricingEngine = new PricingEngine();` to create an instance of the `PricingEngine` class.
2. **Calling `calculateFinalPrice`:**
   - We used the instance `pricingEngine` to call the `calculateFinalPrice` method, which now works correctly as it is not a static method.
