To fix the compilation error related to the `Map` class not being imported, we need to import it at the beginning of the `QwenTest20` class. Here is the corrected Java file:

```java
package com.viktor.lab4.autogen;

import org.junit.Test;
import static org.junit.Assert.*;
import java.util.Map;

public class QwenTest20 {

    @Test(timeout = 1000)
    public void testParseSimpleJson() {
        SimpleJsonParser parser = new SimpleJsonParser();
        String input = "{\"name\":\"John\", \"age\":30}";
        Object parsedValue = parser.parse(input);
        assertEquals("John", ((Map<String, Object>) parsedValue).get("name"));
        assertEquals(30.0, ((Map<String, Object>) parsedValue).get("age"), 0.001);
    }
}
```

This change adds the import statement for `java.util.Map` at the beginning of the class, which resolves the compilation error.
