To fix the compilation error, we need to import the `Map` and `HashMap` classes from the `java.util` package. Here is the corrected Java file:

```java
package com.viktor.lab4.autogen;

import org.junit.Test;
import static org.junit.Assert.*;

import java.util.HashMap;
import java.util.Map;

public class QwenTest52 {

    private static final String JSON_INPUT = "{\"name\":\"John\", \"age\":30}";

    @Test(timeout = 1000)
    public void testParseJSON() {
        SimpleJsonParser parser = new SimpleJsonParser();
        Object result = parser.parse(JSON_INPUT);
        Map<String, Object> expected = new HashMap<>();
        expected.put("name", "John");
        expected.put("age", 30);

        assertEquals(expected, result);
    }
}
```
